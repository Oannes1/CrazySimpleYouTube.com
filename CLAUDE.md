# Project instructions

## Writing style (applies to ALL output: emails, documents, speeches, copy, code comments, everything)

- NEVER use em-dashes or en-dashes as punctuation. Not in any deliverable, ever. Use a comma, a period, an ellipsis, or split the sentence instead.
- Plain, direct sentences. No corporate filler.
- Aaron's voice is conversational and punchy. Short sentences hit harder than clever ones.
